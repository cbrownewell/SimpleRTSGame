# SimpleRTSGame
A project meant to try and create a simple real time strategy game.

Features include, but not limited to:
- Harvesting multiple types of resources (two or three?)
- Recruiting game units
- Commanding game units to perform actions
  - Combat unit will attack other game units and attack buildings
- TBD

This is meant to be a fun exercise for me to explore game development/game programming and since I really like strategy games and have always wondered how they work under the hood.

Most complex assets were downloaded for free from Kenny: https://kenney.nl/assets
  - Hexagon Kit for Buildings & Terrain: https://kenney.nl/assets/hexagon-kit
  - Survival Kit for Equipment: https://kenney.nl/assets/survival-kit
